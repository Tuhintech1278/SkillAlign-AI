# SkillAlign AI

AI-powered Labour Market Intelligence and Curriculum Alignment Platform.

## Features

- Labour market and job data analysis
- Skill demand analysis
- Skill gap identification
- Course recommendations
- Curriculum alignment
- District-level training planning
- Employer feedback insights

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Pandas
- NumPy
- Scikit-learn

## How to Run

### 1. Clone the repository

git clone https://github.com/Tuhintech1278/SkillAlign-AI.git

### 2. Open the project folder

cd SkillAlign-AI

### 3. Install dependencies

py -m pip install -r requirements.txt

### 4. Run the Flask application

py app.py

### 5. Open in browser

http://127.0.0.1:5000
